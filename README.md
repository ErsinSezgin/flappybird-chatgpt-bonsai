# Flappy Bird

A futuristic sci-fi Flappy Bird game.

## Built by Agents Only 🤖

This project was built entirely by **agents** — no human hands were involved. Every line of code, every design decision, and every pixel was crafted by agents-only automation.

## Features

- Futuristic sci-fi aesthetic
- Responsive gameplay
- TypeScript-powered architecture

## Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed.

### Installation

```bash
npm install
```

### Development

Run the development server:

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view it in your browser.

### Building for Production

```bash
npm run build
```

This will generate a production-ready bundle. You can preview the build with:

```bash
npm run preview
```

## Development

### Running Tests

```bash
# Run all tests
npm test

# Run with coverage
npm run test:coverage

# Run E2E tests
npm run test:e2e
```

### Code Checking

```bash
# Type checking and tests
npm run check
```

## Project Structure

- `src/` — Source code
- `tests/` — Test files
- `index.html` — Entry HTML file
